# Ironvale brand kit

Original logo, designed for Ironvale. Hexagon (an iron nut / vault) + a V for "vale" + an orange wave line for the sea.

| File | Use |
|---|---|
| `ironvale-logo.svg/.png` | Main logo on light backgrounds |
| `ironvale-logo-white.svg` | On dark or photo backgrounds |
| `ironvale-logo-on-navy.svg/.png` | Logo on navy panel |
| `ironvale-mark.svg/.png`, `ironvale-mark-white.svg` | Symbol only |
| `ironvale-icon.svg/.png` | App icon, social profile picture, favicon |

Colours: Navy `#0A1A33`, Signal orange `#FF5A1F`, Mist `#F3F6FA`. Wordmark: Inter ExtraBold (SIL OFL), outlined to paths.

## Trademark
Using the symbol (TM) next to "Ironvale" claims it as your brand, no registration needed. The registered symbol (R) may only be used after the trademark office has registered it.
To register: search first (India: IP India public search, trademarkregistry.gov.in; also check the countries you sell in), then file under a relevant class (e.g. Class 35/41/45 for staffing and recruitment services) with this logo and word. A trademark attorney is recommended. Registration is not guaranteed and takes months.
